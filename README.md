# School Admission System

A full-stack FCFS (First Come, First Served) School Admission System built with .NET 8, PostgreSQL, React 18, and Docker Compose.

## Tech Stack
- **Backend:** ASP.NET Core Web API (.NET 8), Entity Framework Core
- **Database:** PostgreSQL 17
- **Frontend:** React 18 (Vite), Axios, CSS Modules
- **Testing:** xUnit, EF Core PostgreSQL Test Runner
- **Deployment:** Docker Compose
